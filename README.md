# Manateq Investor Portal (Next.js)

A static Next.js/React implementation inspired by the Manateq Investor Portal figma prototype. The project recreates navigation, dashboards, project galleries, and authentication flows with a dark glassmorphism visual language.

## Getting Started

Install dependencies and run the dev server (requires internet access to download npm packages):

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the experience. Key routes:

- `/` – Overview hero and prototype summary
- `/dashboard` – Executive dashboard widgets
- `/projects` – Project pipeline gallery
- `/projects/[slug]` – Detailed project page (e.g. `/projects/qetaifan`)
- `/auth/login` – Authentication screen

## Notes

This repository is optimized for showcasing the layout and style of the referenced prototype. Data is static for predictability and offline review.
